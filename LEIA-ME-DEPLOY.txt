========================================
  FISIOAGENDA - COMO SUBIR NA HOSTINGER
========================================

PASSO 1 - BANCO DE DADOS
------------------------
1. Entre no hPanel da Hostinger
2. Bancos de dados MySQL > Criar banco + usuario
3. Abra phpMyAdmin
4. Importe o arquivo: api/database.sql

PASSO 2 - CONFIGURAR API
------------------------
1. Nao edite api/config.php (ele vem do Git, sem senha)
2. Copie api/config.local.example.php para api/config.local.php
3. Preencha:

   DB_PASS   = senha do MySQL
   API_TOKEN = senha que a tela da agenda vai pedir

PASSO 3 - ENVIAR ARQUIVOS
-------------------------
Com Git, siga HOSTINGER-GIT.md.

Subdominio fisio, se for FTP: envie para
  domains/fisio.sthevandev.com.br/public_html/

Arquivos:
  - index.html
  - .htaccess
  - api.php
  - pasta css/
  - pasta js/
  - pasta api/

PASSO 4 - TESTAR
----------------
1. https://SEUDOMINIO.com/api/health  (deve retornar JSON ok)
2. https://SEUDOMINIO.com             (abrir o sistema)

Auto-deploy Git? Leia HOSTINGER-GIT.md
Duvidas? Leia HOSTINGER.md
